## Chapter introduction — checked against the uploaded PDF

The chapter begins with a quotation from *Design Patterns: Elements of Reusable Object-Oriented Software*, then explains why classes and design patterns are useful.

A **class** encapsulates data and the methods that operate on it. Classes support the way developers organize computation, enabling encapsulation and reuse through inheritance and polymorphism. At the same time, careless object-oriented design can produce programs that are difficult to maintain.

A **design pattern** is a reusable description of a solution to a recurring design problem. It is not a complete implementation to copy verbatim. Object-oriented patterns aim to improve reuse and maintainability, especially by allowing different parts of a system to evolve independently.

The introduction also points readers toward the authors' design-patterns course notes, homework and labs as further learning resources.
